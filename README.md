# Description

**This plugin simplifies various vanilla commands and includes some quality-of-life features for simple use**

**Disclaimer:** Not all plugin builds support every feature! For example, if a feature is added in Minecraft 1.21.6, it will not be available in plugin versions built for earlier Minecraft versions such as 1.21.1, So in simple terms no backporting.

**Current Features**
| Features              | Support     |
|-----------------------|-------------|
| **Attributes**        |  🟧 **Partial** |
| **Player Managemnet** |  🟥 **None**    |
| **TP Utilities**      |  ✅ **Full**    |


**Currently Supported Commands**
| Command Names | In Game Command | Plugin version   |
|---------------|-----------------|------------------|
| Size          | /size           | **1.0** or later |
| Health        | /health         | **1.0** or later |
| Speed         | /speed          | **1.1** or later |
| Heal          | /heal           | **1.1** or later |
| Invincible    | /god            | **1.1** or later |
| TP Here       | /tphere         | **1.1** or later |
| TP All        | /tpall          | **1.1** or later |
